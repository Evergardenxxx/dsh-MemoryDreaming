# 仓库审查与修复记录

日期：2026-10-26。起点提交：`a4a2371`（v0.4）。方法：读取源码与现有测试，使用临时 SQLite 数据库复现边界行为，参考公开实现；未复现参考项目的性能分数。本稿由 AI 辅助完成源码审查和归纳。

现有领域划分与 SQLite 基础可以继续使用。本轮优先修复数据隔离、来源失效、检索时间和整理流程错误。下一阶段应先补可靠队列、完整遗忘和宿主适配，再扩展模型能力。

## 本轮已修复

| 问题 | 原行为与后果 | 修复行为 |
|---|---|---|
| 活动恢复只校验角色 | 两个用户使用相同角色 ID，可读到对方的指定活动 | 验证用户、角色和范围；observe 关联活动前验证 |
| 全局事件幂等键 | 相同客户端键返回另一个用户的原始消息 | 完整作用域唯一键；同键不同消息拒绝 |
| 检索作用域不完整 | 其他领域、关系、活动内容挤占或混入结果 | 共用 scope_sql，在 LIMIT 前过滤，pipeline 再校验 |
| 摘要与任务丢失范围 | 入库后可能跨领域整理 | 持久保存完整 scope；摘要按精确生成范围和主题唯一 |
| 删除上限 1000 | 静默遗留其余记录 | 完整 ID 枚举，事务内解析范围和删除 |
| 来源删除传播错误 | 不等长路径和循环依赖留下无来源内容 | 分析受影响子图，只保留仍有外部有效来源的部分 |
| 摘要失效不及时 | 删除和纠正后仍恢复旧摘要正文 | 来源变化同步标 stale，失效摘要拒绝展开 |
| 虚构领域渲染异常 | 访问不存在的 memory.domain | 改为 memory.scope.domain |
| 周/月/年多算一天 | 上周覆盖八天，上月包含本月第一天 | 统一左闭右开边界 |
| “继续”取消硬时间 | 指定日期或传入范围被降级 | 只软化有限的当前时间延续表达 |
| 历史查询混入未来摘要 | as_of 仍输出当前摘要正文 | 历史检索跳过无版本的当前摘要 |
| token 预算超支 | 第一条证据、摘要、围栏没有完整计量 | 对完整渲染上下文估算和裁剪 |
| FTS 降级漏长词 | 长词没进入 LIKE | 全部有效词进入降级路径 |
| 重建向量删错范围 | 清掉其他领域或活动的向量 | 清理与读取采用同一范围，移除 10000 条截断 |
| 整理任务饥饿 | extract 反复领取释放，后续任务无法执行 | 只领取当前有执行器的任务类型 |
| 规则抽取制造事实 | 假设、引述变成用户事实，称呼重复，多偏好漏抽 | 保守过滤语境、分句抽取、互斥称呼规则 |
| 乱序冲突破坏时间线 | 补录旧事件使较新事实提前失效 | 按生效时间、实际 scope、模态和依据比较 |
| 近似去重丢失差异 | 不同活动、模态或语义三元组被合并 | 严格分组后再做近似去重 |
| 未来事实被标当前 | 未检查 valid_from | 加入有效期起点判断 |
| 核心读改写与版本 | 事务外合并；rejected 仍被恢复 | 事务内读改写；跳过 rejected，版本号不重用 |
| 数据库版本被覆盖 | 旧程序可静默写低 schema_version | schema v4 原子迁移，拒绝未来版本 |

## 升级与验证

schema v3 自动迁移到 v4，保留原始事件和 ID，补全可确定的任务范围。旧摘要缺少可靠范围，先标 stale，随后可重建。迁移不会修复过去已经串入核心、误合并或误归因的数据，需要按来源核查。重要数据库应保留迁移前备份，便于回退。

- 原有 89 个测试通过；新增 44 个边界回归后，共 133 个通过。
- `python -m memorydreaming eval`：原有计分用例通过，两个同义改写观察项仍失败。
- `python -m memorydreaming demo`：完整演示通过。
- `git diff --check`：通过。

新增回归位于 `tests/test_storage_regressions.py`、`test_runtime_regressions.py`、`test_retrieval_regressions.py`、`test_consolidation_regressions.py`。本轮未连接真实模型服务，未复现上游性能分数，未做强制结束 worker 的恢复测试。

## 后续优先级

1. **完整遗忘**：已删事实的原始事件和核心仍保留，换提取版本重跑可让它复活；本轮只修复逻辑删除与传播。
2. **崩溃恢复**：缺租约、心跳和过期 worker 的提交隔离。
3. **产品接入**：没有宿主钩子，无法自动保证首次回复前恢复身份。
4. **真实语言理解**：哈希嵌入没有同义语义，规则抽取不覆盖开放语言。
5. **双时间与核心治理**：缺失效获知时间、修订日志、类型化证据与候选审批；核心仍为角色级档案。
