# MemoryDreaming

面向长期陪伴角色的持久记忆引擎，让身份、关系、共同经历和未完成活动能够跨对话窗口与进程恢复。

当前处于架构设计阶段，技术栈尚未确定。

## 设计方向

- 以固定角色 ID 加载版本化的身份核心与关系档案。
- 分别组织工作记忆、情景记忆、语义记忆和程序记忆。
- 根据多标签相关度安排检索顺序、候选预算与回源展开。
- 保留原始证据，支持事实纠正、记忆删除和派生内容同步更新。
- 用最近 48 小时控制默认检索粒度，持续保留旧事件精确回查能力。

## 架构文档

[长期记忆引擎架构草案 v0.1](docs/memory-engine-architecture-v0.1.md) 包含参考项目核查、数据格式、检索流程、时间策略、接口和验收场景。其中的技术方案为待实现、待验证的提案。

## 初期范围

先完成身份恢复、原始事件保存、四类记忆基本结构、持久工作检查点、检索和纠错，再评估巩固、遗忘与角色成长机制。
